# CLAUDE.md

This repository *is* a job: the weekday PR-readiness triage for
reflex-dev/reflex. If you were pointed here to "run it", invoke the
`reflex-pr-readiness` skill (`.claude/skills/reflex-pr-readiness/SKILL.md`)
and follow it end to end, including the commit and push to `main`.

Rules that hold for any work in this repo:

- Read `.claude/skills/reflex-pr-readiness/references/traps.md` before
  touching data collection. It is the accumulated memory of the job.
- Runs are append-only under `cache/runs/<date>/`. Never delete or rewrite an
  old run; add an `ABORTED.md` if one is incomplete.
- `artifacts/index.html` is generated by `scripts/render.py`. Change the data
  or the renderer, not the HTML.
- `cache/repo.git/` is a gitignored bare mirror; rebuild with
  `scripts/prscan.sh fetch-main`.
- Push to `main` when a run completes. Do not open pull requests for runs.
- When a run discovers a new way the board can be wrong, add it to
  `traps.md` in the same commit as the run.
- Scripts are Python 3.11 stdlib + bash + jq + git. Keep them dependency-free.
